# COMMAND AI

A browser-based command dashboard.

## Publish with GitHub Pages
1. Create a **public** GitHub repository.
2. Upload `index.html`, `.nojekyll`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then save.
6. Wait for the Pages deployment to finish. The site URL will appear in the Pages settings.

Note: the AI/demo features in this build run locally in the browser; this is not a hosted AI service.
